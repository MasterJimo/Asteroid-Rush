PRIVACY POLICY

Information about the current Asteroid Rush game.

Last updated: 20 October 2026

Current status: This version does not include advertising scripts, analytics, payment checkouts or player accounts. Review and update this notice before introducing those services.

Who operates Asteroid Rush?

Asteroid Rush was created by MrJim. For public project questions, use GitHub Issues. Issues are public; do not post personal or sensitive information. A private contact channel and any required legal publisher details must be added before monetisation.

Gameplay data

The game processes score, lives, wave and movement in your browser. It does not currently upload scores to a leaderboard or offer player accounts.

Data & Storage

Asteroid Rush remembers your highest score and sound preferences using browser localStorage:

  • asteroidRush.best — personal best score.
  • asteroidRush.track — selected soundtrack.
  • asteroidRush.musicVolume — music volume.
  • asteroidRush.sfxVolume — sound effects volume.
  • asteroidRush.audioDefaultsV2 — marker for the one-time audio default setup.

These values are local preferences, not ad identifiers. You can change audio choices in Settings or clear this site's stored data via your browser settings. Clearing storage also resets your high score. The current game does not install advertising cookies.

Hosting and other services

The game loads its code and the audio file ai_fight_120bpm.ogg from the site serving the game. If hosted on GitHub Pages, GitHub may process connection data (including IP addresses and request details) to deliver the site. See the GitHub privacy statement. Network and hosting providers may process technical data separately from the game's local storage.

Advertising and consent

There are no ads or advertising-consent preferences in the current game. If AdSense is added, this policy will describe the actual providers, identifiers, cookies and data uses, and the publisher will configure a Google-certified consent management platform where required. Privacy links are not consent controls.

Payments

Payment and donation checkouts are not currently offered. Asteroid Rush does not ask for card details.

Updates

This notice will be updated when data practices change. Public project questions can be raised via GitHub Issues without including private information.
