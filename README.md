# Asteroid Rush 🚀

Neonowa gra arcade w stylu klasycznych *Asteroids*, działająca **offline w przeglądarce**. Nie potrzebujesz instalować żadnych programów ani uruchamiać serwera.

## Jak uruchomić grę

1. Kliknij **Code → Download ZIP** na stronie repozytorium.
2. Rozpakuj pobrany plik ZIP.
3. W rozpakowanym folderze znajdź **index.html**.
4. Kliknij dwukrotnie plik `index.html` (otworzy się w domyślnej przeglądarce) albo przeciągnij go na okno Chrome.

## Sterowanie

| Klawisz | Akcja |
| --- | --- |
| ← / → lub A / D | Obrót statku |
| ↑ lub W | Silnik / przyspieszanie |
| Spacja | Strzał |
| P | Pauza |
| Enter | Start / restart |

Na telefonie pod grą są przyciski dotykowe.

## Zasady

Rozbijaj asteroidy na coraz mniejsze części, unikaj kolizji i przechodź kolejne fale. Masz trzy życia. Rekord zapisuje się lokalnie w przeglądarce.

## Muzyka i efekty

W panelu **Settings** można ustawić oddzielnie głośność **SFX** (efekty) i **Music** (muzyka), a także wybrać jeden z trzech oryginalnych utworów:

- **Nebula Drift — Chill**: spokojne, kosmiczne brzmienie.
- **Bass Reactor — Techno**: szybszy rytm i mocny elektroniczny bas.
- **Vector Frenzy — Hyper Techno (192 BPM)**: bardzo szybki, intensywny elektroniczny utwór z mocną perkusją i dynamicznym arpeggiem.

Muzyka startuje po rozpoczęciu gry, zatrzymuje się przy pauzie i końcu rozgrywki. Przycisk **Mute All** wycisza jednocześnie muzykę i SFX. Cała muzyka jest generowana lokalnie przez przeglądarkę — nie wymaga pobierania plików audio.

Wszystko jest zawarte w pojedynczym pliku `index.html` — bez zewnętrznych zasobów, bibliotek i połączenia z internetem.
